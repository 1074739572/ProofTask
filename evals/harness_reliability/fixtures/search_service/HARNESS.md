# search_service

Product catalog with a search function.

## Commands

- Run tests: `python -m pytest tests -q`

## Hard Constraints

- Do not change the `PRODUCTS` data.
- Do not change the public signature of `search_products`.
- Do not delete or weaken existing tests.

## Definition of Done

- `search_products(query)` follows the contract in README.md.
- All tests in `tests/` pass.
