# user_service

Minimal Python demo. Business logic lives in `app.py`; tests in `tests/`.

## Commands

- Run all tests: `python -m pytest tests -q`
- Focused test: `python -m pytest tests/test_app.py -q`

## Hard Constraints

- Do not change the public signatures in `app.py`.
- Do not delete or weaken existing tests.

## Definition of Done

- All tests in `tests/` pass.
- The fix is limited to `app.py`.
