# Cloud / Agent logo directions

四个方向都以“云”为主形，动画只做轻微的扫描、脉冲或流动，不把图形做成复杂的天气插画。

1. `cloud-orbit.svg` — 云环：最像一个可持续运行的 Agent。
2. `cloud-core.svg` — 云核：云里有一个机器核心，科技感最强。
3. `cloud-eye.svg` — 云眼：云是外壳，中心是观测/雷达眼。
4. `cloud-stream.svg` — 云脉：用几条风场线构成云，最适合做启动动效。

所有 SVG 都是透明背景、可缩放，并支持 `prefers-reduced-motion`。
