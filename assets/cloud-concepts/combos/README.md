# Cloud × Agent 组合稿

这组稿子把三个设计语言拆开再排列组合：

- A：单一云形实体轮廓
- B：风场/流线
- C：N 形节点（代表南新/Agent）

所有 SVG 都是透明背景、可缩放，并带有很轻的 CSS 动效；支持 `prefers-reduced-motion`。

## 文件

| 文件 | 组合 |
| --- | --- |
| `cloud-mass.svg` | A，单色云形 |
| `airflow-cloud.svg` | B，线条云 + 风场 |
| `cloud-n.svg` | A+C，实体云 + N 留白 |
| `flow-mass.svg` | A+B，实体云 + 风场 |
| `cloud-n-signal.svg` | A+C，另加运行信号 |
| `flow-n.svg` | B+C，风场云 + N 节点 |
| `full-cloud-system.svg` | A+B+C，完整组合 |

这些是探索稿，不是对 DeepSeek、南信大或其他品牌商标的复制。
